# SNHU_CS-230\
The Gaming Room Project Software Design\
&nbsp;&nbsp;&nbsp;The Gaming Room is a simulated client company that developed the game "Draw It or Lose It!" for Android devices. They wanted to develop a program to run their game across multiple platforms.\
&nbsp;&nbsp;&nbsp;In developing this documentation, I did well in analyzing individual components and issues of the system. However, it would benefit from a revision where I better keep in mind the whole of the project. I missed the forest for the trees, so to speak.\
&nbsp;&nbsp;&nbsp;Working through the design document was particularly helpful in managing "scope creep" and ensuring the appropriate features are prioritized.\
&nbsp;&nbsp;&nbsp;Interpreting the needs of the program was a matter of determining what already existed and from that considering the necessary foundations to bridge into the new goals.\
&nbsp;&nbsp;&nbsp;In the future, I'm certainly going to utilize the Unified Modeling Language more. It helps a great deal to have a map detailing each element of the program and helping identify what is missing or what already exists and can be reused.\
